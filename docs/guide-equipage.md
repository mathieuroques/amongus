# Guide de l’équipage

## Votre objectif
Terminer **toutes les tâches de l’équipage** ou **éjecter tous les imposteurs**. Les tâches des fantômes comptent aussi.

## Faire une tâche
1. Onglet **Tâches** : repérez la pièce et le poste de la prochaine étape.
2. Marchez jusqu’au poste (sans courir, sans regarder votre écran dans l’escalier).
3. Onglet **Poste** → « Scanner le QR code » (ou tapez le code imprimé sous le QR code).
4. Choisissez la tâche, réussissez le mini-jeu. Attendez « Tâche terminée ✔ ».
5. Tâche longue : la 2ᵉ étape se fait à un autre poste (indiqué dans la liste).

Les mini-jeux : relier des fils, mémoriser une séquence, toucher des nombres dans l’ordre, arrêter un curseur, aligner un curseur, transfert de données (rester au poste), scan médical, glisser un badge, toucher des cibles, compter des symboles sur la fiche, reconstituer un mot avec des bandes de papier (pensez à remélanger les bandes après).

Pendant une **panne de courant**, les postes sont hors service : allez réparer au poste Énergie. Pendant une **coupure des communications**, votre liste disparaît : réparez au poste Radio, ou faites de mémoire une tâche dont vous connaissez le poste.

## Se défendre et enquêter
- Le **scan médical** affiche un grand écran vert visible de loin : faites-le devant témoins pour vous innocenter.
- Le **moniteur de vie** (poste dédié) indique qui est mort, même avant la réunion.
- Retenez qui était avec qui, et où. Un joueur qui sort d’un **conduit** est un imposteur.
- Rien ne se prouve en montrant son téléphone : n’importe qui peut afficher une fausse carte « Équipage ».

## Si vous êtes éliminé·e
Un imposteur vous touche l’épaule et vous montre un code : ouvrez **Urgence**, tapez-le tout de suite. Puis asseyez-vous sur place, en silence, votre code de corps visible. Ne révélez jamais qui vous a tué·e. Ensuite, lisez le guide des fantômes.

## Trouver un corps
Onglet **Urgence** → tapez le code affiché sur le téléphone du corps → la réunion commence.

## Réparer un sabotage critique
- **Réacteur** : il faut une personne à **chacun** des deux postes Réacteur, qui maintiennent le bouton **en même temps** quelques secondes. Coordonnez-vous à voix haute !
- **Oxygène** : allez aux deux postes Oxygène et recopiez le code affiché à chacun.
Si le compte à rebours atteint zéro, les imposteurs gagnent.
