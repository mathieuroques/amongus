# Checklists

## Quelques jours avant
- [ ] Site en ligne et testé (voir README) ; lien noté.
- [ ] Partie créée, **code maître du jeu noté** sur papier.
- [ ] Pièces, postes, tâches et consignes de sécurité saisis et **enregistrés**.
- [ ] Terrain **exporté** (fichier de sauvegarde).
- [ ] Fiches, étiquettes, panneaux, badges et affiche d’invitation imprimés (fiches « puzzle » imprimées avec la version actuelle : bandes à deux lettres, haut et bas).
- [ ] Message aux invités : charger leur téléphone, venir avec un navigateur à jour, partager le Wi-Fi.

## Le jour J, avant l’arrivée des joueurs
- [ ] Fiches posées (aucune dans un escalier ; « Énergie » loin du vrai tableau électrique).
- [ ] Zones interdites signalées ; sorties et escaliers dégagés ; lumières allumées.
- [ ] Chaque QR code vérifié (onglet 🧪 Tests → « Vérifier une fiche posée »).
- [ ] Toutes les tâches et réparations testées (onglet 🧪 Tests : « x/y vérifiés »).
- [ ] Affiche d’invitation à l’entrée ; Wi-Fi des invités disponible.
- [ ] Téléphone du MJ chargé (+ batterie externe) ; tableau de bord ouvert.

## Juste avant de démarrer
- [ ] Tous les joueurs dans le salon ; salon verrouillé.
- [ ] Nombre d’imposteurs adapté (conseil affiché).
- [ ] Présentation de sécurité faite (zones interdites, passages, sorties, on ne court pas, élimination douce, Alerte sécurité, écran STOP).
- [ ] Demandé qui souhaite l’élimination « sans contact ».
- [ ] Rappel : on ne montre pas son téléphone, on ne photographie pas les postes, les fantômes se taisent.
- [ ] Chaque joueur a réglé ses alertes (son, notifications, écran allumé) et testé son appareil photo dans le salon.
- [ ] « Faire sonner tous les téléphones » : chacun a levé la main.
- [ ] Badges fantômes et pinces à disposition dans la salle de réunion.

## Pendant la partie
- [ ] Surveiller les alertes et les joueurs déconnectés (⚪).
- [ ] Ramasser les bandes de papier mélangées si besoin.
- [ ] Pause en cas d’incident ; arrêt d’urgence si nécessaire.

## Fin de partie
- [ ] Lire le récapitulatif à voix haute (rôles, éliminations, votes).
- [ ] Soit **Nouvelle partie** (mêmes joueurs et réglages), soit fin de soirée.
- [ ] Vérifier que personne n’est resté dans une pièce isolée.
- [ ] Récupérer les fiches, étiquettes, badges et adhésifs ; remettre les meubles et les pièces en ordre.
- [ ] Rien à supprimer côté données : le serveur ne garde que les pseudonymes et l’état de la partie, effacés automatiquement 7 jours après la dernière activité. Exportez le terrain si vous voulez le garder ailleurs que sur votre appareil.
