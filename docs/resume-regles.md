# Résumé des règles (à lire en 2 minutes)

**But du jeu** — L’**équipage** gagne en terminant toutes ses tâches ou en éjectant tous les imposteurs. Les **imposteurs** gagnent quand ils sont aussi nombreux que l’équipage vivant, ou si un sabotage critique (réacteur, oxygène) n’est pas réparé à temps.

**Sécurité d’abord** — On marche, on ne court jamais. Aucune porte verrouillée. Zones interdites ⛔ respectées. Pas de contact brusque. Onglet *Urgence → Alerte sécurité* au moindre souci. Écran rouge STOP = on s’arrête.

**Tâches** — Allez au poste indiqué (onglet *Tâches*), scannez son QR code (onglet *Poste*), réussissez le mini-jeu. Le « scan médical » vert est une preuve d’innocence.

**Élimination** — L’imposteur touche l’épaule et montre un code à 4 chiffres ; la victime le tape aussitôt (onglet *Urgence*). Jamais dans un escalier ou un passage.

**Corps** — La victime s’assoit sur place en silence, son code de corps affiché. Celui qui la trouve tape ce code (onglet *Urgence*) → réunion.

**Réunion d’urgence** — Au bouton d’urgence (salle de réunion) : 1 par joueur, pas pendant un sabotage.

**Réunion** — Rassemblement → discussion → vote (un joueur ou « passer », vote définitif). Le plus de voix est éjecté ; égalité ou « passer » majoritaire : personne. Le rôle de l’éjecté est annoncé.

**Sabotages** — Réacteur : deux personnes maintiennent le bouton en même temps aux deux postes Réacteur. Oxygène : recopier le code aux deux postes Oxygène. Panne de courant : postes de tâches hors service → poste Énergie. Communications : liste des tâches masquée → poste Radio.

**Fantômes** — Silence total avec les vivants, badge visible. L’équipage fantôme finit ses tâches ; l’imposteur fantôme peut saboter. Pas de vote, pas de signalement, pas de réparation.

**Bluff** — Montrer son téléphone ne prouve rien : tout le monde peut afficher une fausse carte « Équipage ».
